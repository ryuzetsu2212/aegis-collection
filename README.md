# Aegis Collection

Concept site for an AI-powered fashion merchandising platform
("Autonomous Fashion Intelligence & Merchandising Engine"), built with Next.js.

Live: https://aegiscollection.biz.id

Dibuat sebagai materi pendaftaran program Claude for Startups.

## Tech

- Next.js 16 (App Router), React, TypeScript, Tailwind CSS
- Single-page marketing site + konsol demo interaktif (UI prototype)

## Catatan

- Konsol demo di halaman utama adalah prototype antarmuka; integrasi API live menyusul.
- Tier harga yang tampil adalah rencana, bukan layanan berbayar aktif.
